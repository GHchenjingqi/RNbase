## 四、每项落地技术要点

### P0-1 React 错误边界
- 新增 `src/components/AppErrorBoundary.tsx`：捕获渲染期异常，渲染降级 UI（与 `WebViewErrorPage` 同风格的居中卡片），并 `ErrorUtils.setGlobalHandler` 接 `observability` 上报。
- 在 `App.tsx` 的 `SafeAreaProvider` 内、`WebViewBridge` 外包一层；同步给 Harmony 的 `Index.ets` 注册全局异常。

### P0-2 崩溃上报闭环
- JS 层：`ErrorUtils.setGlobalHandler` + `Promise` 未处理 `unhandledrejection`（H5 侧已上报，RN 侧补全局 handler）写入 `device-logger`。
- 原生层：Android `Thread.setDefaultUncaughtExceptionHandler` 写本地 ring buffer，下次启动由 `log-manager` 补报；接入 Sentry React Native（`@sentry/react-native`）仅做桥接，不破坏现有 `log-entry` 模型。

### P0-3 CI/CD（GitHub Actions）
- `.github/workflows/ci.yml`：`setup-node` → `npm ci` → `npm run typecheck` → `lint` → `format:check` → `npm test -- --coverage`（覆盖率门槛如 src 行覆盖 ≥80%）。
- `.github/workflows/android.yml`：PR 触发 `assembleDebug`（unsigned）确保安卓可编；出 release 单独 manual workflow（签名走 secrets）。

### P0-4 远程模式兜底
- `web-view-controller.ts` 增加「页面 200 但 X 秒无交互/无首屏标记」的软超时，超时走 `WebViewErrorPage`（已有三按钮）。
- 给远程模式加可选离线兜底页（内置 `assets/offline.html`），断网即显示，不依赖第三方。

### P1 iOS 补齐
- `resolve-h5-entry.ts` 增加 `isIos()` 分支返回 `file://` 指向 Bundle 资源（`[[NSBundle mainBundle] pathForResource]` 经原生方法暴露），并复用 `appendCacheBustQuery` 注意 iOS WKWebView 缓存策略。
- `config/index.ts` `CLIENT_ID.ios` 接入环境变量/打包脚本注入，避免硬编码占位。
- 鸿蒙已验证的 Bridge 模块（`bridge/index.ts` 注册表）在 iOS 侧逐项补原生实现，未实现的方法保持 `DEVICE_UNSUPPORTED`；`ios:doctor` 自动列出未注册项。
- `build:ios:release` 补齐 `ExportOptions.plist` 与签名参数模板（仍由 secrets 提供，不入库）。

### P2 安全闭环
- `verifier.ts`：把「可选数字签名」改为「清单声明 `signature` 字段时强制校验，缺失则拒绝」，并新增 `manifest` 完整性校验。
- 新增 `src/security/ssl-pinning.ts` + 原生信任管理器（Android `network-security-config`、iOS `Info.plist` 公钥锁定），仅对 `H5_MANIFEST_URL` 与下载域名生效。
- `src/security/device-integrity.ts`：root/jailbreak 检测，结果进 `deviceInfo` 与 Bridge 调用策略（高风险操作二次确认）。

### P3 基座能力补全（范围已按「仅通用基座能力」裁剪）
- ~~i18n~~：**不做**——多语言文案属 H5 业务层职责，基座不预留框架（见范围边界声明）。
- ~~主题 Design Token~~：**不做**——基座已下发 `system.darkmodechange` 环境事件，消费与样式属业务层。
- Feature Flag：`src/config/remote-config.ts` 拉取远端开关（复用 manifest 通道），`PERF_DEFAULT_BASELINES`/能力可见性可由开关控制（通用运行时开关，紧急止血不发版）。
- 文档：`docs/ADR/` 记录关键决策（为何 0.84.1、为何拆两条升级链路）；`CHANGELOG.md` 记录基座演进；`scripts/gen-api-doc.js` 从 `scripts/api.js` 注释生成 H5 能力清单。

# ADR-0001：为何 React Native 固定 0.84.1

- 状态：已接受
- 日期：2026-10-13
- 决策人：基座维护团队

## 背景

基座需要同时支持 Android 与 HarmonyOS（RNOH）。RNOH（React Native OpenHarmony）对 RN
核心版本有强耦合的兼容矩阵：RNOH 0.84.4 要求 RN 0.84.x，更高版本的 RN 无对应的 RNOH
稳定版。升级 RN 会直接破坏鸿蒙构建链路。

## 决策

- `react-native` / `@react-native-community/cli` / `@react-native/metro` 统一固定在 **0.84.1**；
- 鸿蒙侧使用 **RNOH 0.84.4** 及配套 ohos 依赖；
- 升级 RN 必须与 RNOH 版本矩阵联动评估，禁止单独升级 RN。

## 后果

- ✅ 三端（Android/Harmony/iOS）构建链路稳定，`build:harmony` 可产出 unsigned HAP；
- ⚠️ 无法使用 0.84.1 之后的新特性；升级需等 RNOH 跟进，作为独立 ADR 重新评估。
